# Kumbuka – small AI health ledger (hackathon demo)

Phone-accessible medical ledger for patients with basic phones. See [`docs/plan.md`](docs/plan.md) for the full build plan.

Status: work in progress, built as a stack of PRs following the plan's build order.

## Local dev

```sh
npm install
cp .env.example .env   # fill in VITE_SUPABASE_URL / VITE_SUPABASE_PUBLISHABLE_KEY
npm run dev
```
